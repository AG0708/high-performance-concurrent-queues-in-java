# Third-party tools

The queue library itself depends only on the Java runtime. Test and benchmark modules use:

- JUnit 5.14.4 — Eclipse Public License 2.0
- JMH 1.37 — GNU General Public License 2 with the Classpath Exception
- JCStress 0.16 — GNU General Public License 2 with the Classpath Exception
- Maven 3.9.11 and build plugins — Apache License 2.0

Transitive tool dependencies are resolved from Maven Central and recorded by exact versions in the Maven project model.
